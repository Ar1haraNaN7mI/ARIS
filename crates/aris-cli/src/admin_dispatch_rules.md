## Creating worker lanes

Each worker already receives the shared goal. Send the full roster in one `create_sub_agents` call. Use short IDs, a named owner, one specific responsibility and a verifiable deliverable. Keep source material, calculations, operating procedures and acceptance checklists in the shared goal or referenced files. A model can run out of output inside a JSON string even when the gateway reports a function call as finished.

For a new worker, `prompt` is also its first assignment. Put file ownership in `files` and dependencies in `depends_on`. Write each once. When the team already has workers, use `assignments` to give new work to the existing owners who must act. Select profile IDs exactly as listed, declare an acyclic graph, and give each file a single owner among parallel writers.

For a coding task, assign ownership of the implementation and regression coverage in the shared checkout. Parallelize independent changes. Schedule integration checks after the edits they verify and include the command, working directory and observed result in the handoff.

Creation is atomic. An incomplete roster creates zero lanes. If ARIS asks for a replacement, send a complete compact roster from the original goal using the same necessary owners. Omit the partial JSON and repeated prose. A successful creation receipt lists actual worker and session IDs; reuse those lanes for subsequent work.

Walk each required peer exchange before submitting the graph. If A needs B's reply to finish, identify the draft, figures or file A can send while A is running. Give B a co-work action it can perform from that input. When this is B's whole assignment, start B independently; putting A in B's dependencies would make both wait for the other. When B also owns a later task that needs A's finished output, keep that dependency for the later task and distinguish the earlier co-work action in B's prompt. The final publication waits for verified inputs.

Read the failure stage in the receipt. A JSON end-of-input error means the received roster ends mid-value. A provider can also report an exhausted token budget; preserve the original assignment and reference long inputs when regenerating the control call. Older ARIS builds miscounted repeated call IDs and reasoning against a local payload-size limit; current dispatch accepts the full business text. A gateway schema-compilation error occurs before generation; report the named schema field for a controller fix. ARIS supplies the tool schemas. A previous gateway rejected the `uniqueItems` schema keyword; worker IDs and dependency uniqueness are checked in ARIS itself.
