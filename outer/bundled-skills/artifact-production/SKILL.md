description: 把“生成一份……”落实为可打开的交付文件。适用于表格、清单、报告、网页、JSON 和其他由工作区工具支持的格式。Create and verify a requested artifact.
tags: [生成, 报告, 清单, 表格, 文件, 导出, artifact, deliverable, export]

按用户给定的用途、受众、文件名和格式组织交付。若只要求在对话中给出内容，直接在会话交稿。需要文件时，先检查工作区里的源材料和现有文件，再选能原生写出目标格式的工具。

| 交付物 | 生成与验收 |
| --- | --- |
| 报告、文案、策划书 | 使用内置写作原则。以 Markdown 交付时保留可核实的来源、单位和时间窗。对报告中的派生数字调用 `report_calculate`。 |
| CSV、JSON 等结构化数据 | 写出目标格式，用对应解析器重新打开。检查行数、必需字段、编码和单位。 |
| 单页 HTML | 将用户需要的内容写入 HTML。使用可用的页面工具确认页面打开、链接和关键交互。 |
| 剪辑、海报和生成图 | 按 `video-edit` 或 `visual-design` 的步骤调用实际媒体工具，读取导出文件的尺寸、时长或格式。 |
| 其他指定格式 | 先查当前技能和可用的转换器。按该格式导出并重新打开。缺少生成器时，给出能完成的部分和所需依赖。 |

已有工具能直接完成的小任务由当前执行者处理。仅在源材料整理、独立计算或制作环节确实可并行时拆分工作。让每个角色拥有自己的输出文件，整合角色按依赖顺序读取交付结果。

会话结尾给出成品的工作区相对路径，以及读者检查它所需的一项具体信息，例如“清单含 24 行”或“导出视频长 18.2 秒”。所有完成情况以实际文件和工具反馈为准。
