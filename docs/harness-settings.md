# ARIS 设置与数据

工作台的设置入口管理本机运行时。模型、团队模板和执行权限由 Rust 后端持久化；主题、字体与界面密度保存在当前浏览器。

## 模型与团队

KEI API 页面提供登录导入、模型发现和手动模型档案。每个档案指定真实模型 ID、协议、网关、凭据引用，以及可选的图像能力和输出预算。每位智能体选择自己的固定档案；配置修改在下次运行生效。

导入顺序为登录、模型家族、已有或新建 Key、精确模型、返回 ARIS。Key 通过一次性授权码与 PKCE 兑换，保存在本机私有目录，读取设置时只返回引用名称。

模板可自由编辑、另存或新建，支持 1–32 位智能体及其依赖。个人模板保存在 `~/.aris/templates`。运行时为每位成员建立持久会话；总任务消息发起新一轮团队协作，子智能体消息仅重新执行该成员和依赖它的后续阶段。

## 执行与浏览器

工具沿用执行权限、审批策略、插件和 Skills 注册表。工具失败、审批等待、交接与文件快照均记录实际结果。普通聊天和团队工作使用同一运行时。

浏览器功能默认关闭，可在设置中启用。驱动为 Playwright Chromium，每个智能体独立 context、页面、Cookie 和鼠标；不会创建多个系统物理光标。页面截图保存于 `~/.aris/computer/screenshots`，支持图像输入的模型档案可读取这些截图。

旧 Windows UIA/OCR 和透明桌面指针已移除。当前驱动操作网页；不提供任意原生桌面应用控制。浏览器安装方法见 [浏览器适配器](../integrations/browser-runtime/README.md)。网页正文获取使用 [Scrapling](../integrations/scrapling/README.md)。

## 持久化

| 数据 | 默认位置 |
| --- | --- |
| 模型档案 | `~/.aris/kei.json` |
| 导入凭据 | `~/.aris/credentials.d/` |
| 手动保存的密钥 | `~/.aris/credentials.env` |
| 通用设置 | `~/.aris/settings.toml` |
| 个人模板 | `~/.aris/templates/` |
| 团队状态、事件和文件快照 | 工作区 `.aris/teams/` |

`ARIS_HOME` 可改变用户数据根目录。文件快照仅覆盖明确声明的文件；恢复前持久化撤销快照，不改变 Git index/HEAD。运行中的任务结束或取消完成后才能恢复文件。

个人资料保留本地身份与可选访问密码。密码保存随机盐的 Argon2id 校验值；锁定入口后不能读取会话或调用工具。CLI 不使用网页访问密码。

记忆开关控制后续模型调用；全局 `learn.enabled = false` 优先。会话导出包含用户消息与工具输出，但不附带模型凭据或 MCP 连接秘密。进行中的会话拒绝归档或删除。

启动动画、启动录音和桌宠已移除。子流程动画反映实际任务状态，并遵守减少动画偏好。
